GOTOWA STRONA NA 18 URODZINY
=============================

Co jest w paczce:
- index.html  -> gotowa strona
- folder assets -> zdjęcia i filmiki użyte na stronie

Jak to uruchomić u siebie:
1. Rozpakuj paczkę ZIP.
2. Otwórz plik index.html w przeglądarce na komputerze.

Jak zrobić, żeby QR otwierał stronę na telefonie:
1. Wrzuć CAŁY folder strony na darmowy hosting, np. GitHub Pages albo Netlify.
2. Po publikacji dostaniesz link do strony, np. https://twojanazwa.netlify.app
3. Ten link wklej do generatora QR i wydrukuj kod.

Najprostsza opcja:
- Netlify Drop: wgraj cały folder strony.
- GitHub Pages: wrzuć pliki do repozytorium i włącz Pages.

WAŻNE:
QR zacznie działać dopiero wtedy, gdy strona będzie miała publiczny link.
Jeśli chcesz, mogę Ci w kolejnym kroku pomóc:
- podmienić teksty,
- dodać więcej zdjęć,
- zrobić wersję jeszcze bardziej romantyczną,
- przygotować FINALNY kod QR po tym, jak będziesz mieć link.
